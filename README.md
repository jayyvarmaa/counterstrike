# counterstrike

Unreal Engine Multiplayer Shooter (FPS) Project.

## Overview
This repository contains the Unreal Engine project files and assets tracked with Git LFS.

## Setup Requirements
1. **Unreal Engine 5** (or compatible version).
2. **Git LFS** (`git lfs install`).
   When cloning this repository, ensure Git LFS is installed and run:
   ```bash
   git clone https://github.com/jayyvarmaa/counterstrike.git
   cd counterstrike
   git lfs pull
   ```
